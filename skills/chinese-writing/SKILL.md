# 中文写作与润色

帮助作者把意思写准确、写清楚，并保留自己的语气。先处理读者真正需要知道的内容，再调整表达；不要把“像人写的”当成可以改动事实的理由。

## 选择工作方式

从当前请求和已提供的材料判断，不要求用户先填一套表。

| 请求 | 做法 |
| --- | --- |
| 根据要点起草 | 围绕读者、用途和已有材料成稿；欠缺关键事实时留明确占位或集中问一个必要问题。 |
| 润色、去AI腔 | 默认保留原意与信息量，只改有问题的句段；已经自然的表达可以不改。 |
| 大幅重写、调整结构 | 可以重排论点和段落，但保留事实、限定条件和作者立场。 |
| 检查哪里不好 | 指出最影响理解的问题，并给具体修改示例；不要擅自重写全文。 |
| 按本人语气写 | 先读用户给的样本，提取称呼、句长、用词和论证习惯，再处理目标文本；样本里的事实不能移植进新稿。 |

有篇幅、体裁、繁简体、平台或格式要求时优先遵循。缺少可推断的风格信息就采用平实中文；只有会改变正文内容的关键缺口才需要追问。

## 固定信息，再修改表达

动笔前在内部确认必须保留的内容：人物和机构、数字和单位、时间、比较基准、引用、因果强度、否定和条件、说话人的身份及承诺。不必把这份清单输出给用户。

- 不为增加具体感而补造统计数字、文献、政策年份、案例、引语或亲身经历。
- 不把“可能”改成“必然”，不把相关性改成因果性，不把“未发现显著差异”改成“没有差异”。
- 遇到百分比、百分点、增长率与水平值，保持原单位和比较口径。不能为了好读而默默替换。
- 纯润色不等于完成事实核查。遇到材料内的矛盾或明显可疑信息，指出具体位置，不擅自选择一个版本。
- 用户要求补事实时，只把可核实且适用于当前对象的资料写进正文，并提供对应出处；无法核实就说明缺口。
- 直接引语按原文保留。若必须改写，改为明确的转述，不把润色后的文字放进原引号。

## 按中文的表达习惯写

先判断每段要回答什么。需要解释时，把判断与理由接起来；需要行动时，写清谁做什么、何时完成。段落长短服从内容，不追求整齐。

- 优先使用能说明动作的词。“对流程优化工作的推进”可改为“推进流程优化”；如果材料说明了具体改动，直接写改动。
- 主语能帮助辨认责任或对象时写清楚，连续句的主语明确时可以省略。不要把每句都补成冗长的完整句。
- 拆开层层嵌套的定语和抽象名词串。必要的技术术语保留，并用上下文解释；不要给同一个专业概念轮换近义词。
- 只在逻辑需要时使用“因此”“此外”“然而”。删掉连接词后若关系仍然不清，补足理由，而不是换一个连接词。
- 比较、步骤和并列信息可以用列表或表格。连续论证用段落；不把所有文章都写成三点，也不把必要列表硬改为长段。
- 开头尽快进入问题，保留有用的背景。结尾停在结论、限制或下一步，不机械重复正文，也不额外拔高意义。

## 处理AI腔时看问题，不执行禁词表

“赋能”“重要”“不仅……而且……”以及破折号、排比、三点列表本身都不是错误。判断它们是否提供了信息、是否符合作者和读者的语境。

| 具体问题 | 修改方向 |
| --- | --- |
| 评价很多，事实很少 | 删除没有依据的强评价；用原材料中的动作、结果和条件支撑保留的判断。 |
| 同一个意思换词说几遍 | 合并重复句，保留真正新增的信息。 |
| 为了显得深刻强造对比 | 直接说清主张；确实存在的取舍、反驳和对照仍然保留。 |
| 句式和段落机械重复 | 按意思重组句段，让铺垫、例证和判断各有空间，不刻意制造随机长短句。 |
| 翻译腔或堆积抽象概念 | 改成中文常用语序，落实动作和对象；没有具体材料时收窄表达，不编细节填空。 |
| 硬加情绪、口头禅或第一人称 | 回到作者已经表达的态度；正式文本保持正式，不捏造“人味”。 |

需要区分文体或参考前后对照时，按需读[文体与改写示例](references/examples.md)。不要为了使用这个技能而主动加载所有补充文件。

## 排版与交付

遵循用户或目标刊物的排版约定。没有指定时，中文正文使用中文标点和弯引号“”；中英文间距保持全文一致。代码、公式、网址、路径、引用标记和产品名称按其原有语法保留。

默认直接给可用成稿。仅在用户要求解释，或存在会影响使用的事实缺口、歧义时，附简短说明。不要附“AI率”、伪精确质量分、内部检查过程或未经验证的检测器承诺。

交付前对照原材料做一次短检查：有没有丢条件、改数字、换立场、加承诺或造细节；文体是否合适；是否还有不帮助读者的重复。只修实际发现的问题，不无限循环改写。
